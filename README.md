## ☁️ Cara Push ke GitHub & Deploy ke Vercel (Open to Public)

Proyek ini telah dikonfigurasi dengan `vercel.json` dan `next.config.mjs` sehingga **100% siap deploy ke Vercel** tanpa konfigurasi tambahan:

### 1. Push ke Repository GitHub Anda (`Ksatria3739`)
```bash
cd C:\Users\ksatr\.gemini\antigravity\scratch\ksatria-portfolio
git init
git add .
git commit -m "feat: launch futuristic cyber security & full-stack portfolio"
git branch -M main
git remote add origin https://github.com/Ksatria3739/ksatria-portfolio.git
git push -u origin main
```

### 2. Deploy di Vercel (`vercel.com`)
1. Buka **[https://vercel.com/new](https://vercel.com/new)** dan login dengan akun **GitHub (`Ksatria3739`)**.
2. Pilih repository **`ksatria-portfolio`** lalu klik **Import**.
3. Framework Preset akan otomatis terdeteksi sebagai **Next.js**.
4. Klik **Deploy** — dalam ~1 menit website portofolio Anda akan langsung aktif dan *open to public*!
